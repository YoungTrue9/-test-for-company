# Online Courses Catalog — Test Task

Vanilla frontend test task based on the Figma layout.

## Stack

- HTML
- SCSS
- Vanilla JavaScript
- Vite
- BEM methodology

## Implemented

- Pixel-oriented layout based on the provided Figma design
- Responsive course grid
- Live search by course title
- Filtering by categories
- Course cards generated from JS data
- Decorative elements recreated with CSS
- Clean BEM-style class naming

## How to run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes

The layout uses the Lato font from Google Fonts. Course images are stored in `public/images`.
